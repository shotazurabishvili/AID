## Goal

Ingest **WGI from the native World Bank bundle** (not via the `WDI` R package) so that the per-country-year `n_sources` count is retained for engaging the Langbein & Knack (2010) aggregation critique. Per the plan, this is the deliberately separated 2nd Phase-1 session.

## What we did

- Stubbed **ADR-0009** (WGI operationalization in models) — Status: Pending, locked in Phase 5 after VIF is observed. Three options laid out (all-six with VIF + PCA robustness / single-composite / reconstructed-from-sources).
- Probed canonical WGI bundle URL `https://www.worldbank.org/content/dam/sites/govindicators/doc/wgidataset.xlsx` — works (2.1 MB Excel, sha256=`28f7bc1540df…`).
- Inspected bundle structure: 7 sheets (1 introduction + 6 dimensions); each dimension sheet has 13 rows of legend then year+metric headers at rows 14–15, data at row 16+. Each dimension's columns are organized as [Country/Territory, Code, then (year × {Estimate, StdErr, NumSrc, Rank, Lower, Upper}) groups].
- Wrote `R/10_ingest_wgi.R`:
  - Two-URL fetch strategy with manual-download fallback message
  - **Dynamic year-row detection** (search top 25 rows for a row where most cells are 4-digit integers 1990–2030) — robust to small future layout shifts
  - Single-read approach (header rows + data in one frame) to avoid column-count mismatch
  - Pivot long → filter to {Estimate, StdErr, NumSrc} → pivot wide on dimension+metric
  - Retains 18 columns (6 dimensions × 3 metrics)
- Extended `R/lib/iso3.R` overrides to fix 5 WGI-specific country codes:
  - ADO → AND (Andorra)
  - ROM → ROU (Romania)
  - TMP → TLS (Timor-Leste)
  - ZAR → COD (DR Congo)
  - KSV → XKX (Kosovo, WGI variant)
  - ANT → NA (Netherlands Antilles, dissolved 2010)
  - CHI → NA (Channel Islands, non-sovereign — also silences the WDI session warning)
- Re-ran ingest: 5,112 rows (vs 4,992 before override fix), **213 countries**, years 1996–2022, all 18 expected columns. Unresolved log now empty.
- Updated documentation layer per the strengthened CLAUDE.md protocol — see "Methodology entries written this session" below.

## Decisions made

- **No new ADR locked in this session.** ADR-0009 stubbed only — the actual operationalization decision is Phase 5.
- **Per-source detail deferred to Phase 5.** The WGI bundle contains aggregate scores only (with `n_sources` counts as quality flags). True per-source ingestion would require dozens of additional files from the WGI website (one per source organization: EIU, BTI, V-Dem, Freedom House, etc.). For Phase 1 the aggregates + `n_sources` count are sufficient to acknowledge Langbein-Knack; per-source values become a Phase-5 dependency *only if* ADR-0009 selects Option 4. **Plan revised mid-execution** with this scope clarification — captured here and in the data dictionary scope note.
- **iso3 override table extended** to cover both WGI and earlier WDI/HCI edge cases in one canonical place.

## Results / findings

WGI aggregate coverage is unusually clean (95–98% across estimate columns), reflecting WGI's deliberate "fill-as-much-as-possible" methodology. Coverage gaps cluster at:
- Pre-2002 odd years (1997, 1999, 2001) — biennial era; NA by design
- Recent late years for a few small states with delayed reporting

Per-dimension n_sources varies from 1 (some small Pacific states, single-source country-years) to 15+ (well-monitored major countries) — this variance is the substance of the Langbein-Knack critique and what we now retain.
