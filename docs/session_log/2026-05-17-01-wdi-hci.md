## Goal

Phase 1 Session 01: build the shared `R/lib/` helper library and ingest the two cheapest sources via the WDI API (WDI proper, folding in former EdStats education indicators, and HCI).

## What we did

- Wrote four shared helpers under `R/lib/`:
  - `iso3.R` — `normalize_iso3()` with an override table for 8 known edge cases (Kosovo, Taiwan, West Bank & Gaza, South Sudan, North Macedonia, Eswatini, Czechia, Côte d'Ivoire) + cascade through `countrycode` origins; logs unresolved labels to `output/logs/iso3_unresolved_<src>.csv`
  - `io.R` — path helpers (`raw_dir`, `interim_path`, `write_interim`), `hash_raw()` (SHA-256 via `digest`), `raw_is_stale()`, `fetched_on()` for the `.fetched_on` marker file
  - `catalog.R` — `read_catalog()`, `update_catalog()`, `render_catalog()` — manages `data/catalog.yml` as the machine source and re-renders `data/catalog.md` as a sortable table
  - `coverage.R` — `coverage_summary()` (per-indicator stats), `coverage_heatmap()` (faceted country × year tile plot), `ssa_missingness_pattern()` (SSA vs non-SSA gap)
- Seeded `data/catalog.yml` with 11 required source entries (static fields only — name, URL, methodology cite, auth_required, notes)
- Wrote and ran `R/10_ingest_wdi.R` — pulled 13 indicators (4 macro controls + 9 former-EdStats education series) for all countries, 1995–2024. Output: `data/interim/wdi.parquet` (6480 rows, 216 countries)
- Wrote and ran `R/10_ingest_hci.R` — pulled 6 HCI series (overall + female + male × HCI + LAYS), excluding HLOS which is reserved for Session 04. Output: `data/interim/hci.parquet` (2277 rows, 207 countries, only 2010–2020 by HCI release schedule)
- Both ingest scripts cache raw to `data/raw/<src>/<src>_raw.rds`, hash with SHA-256, update catalog programmatically, and re-render `catalog.md`
- One unresolved label per source ("CHI" = Channel Islands in WDI) — correctly excluded as non-sovereign; logged for audit

## Decisions made

- **Macro pipe pattern**: native R `|>` doesn't support magrittr's `{ if(...) . else . }()` placeholder; used a pre-pipe `if (...)` assignment instead. Pattern carried into all future ingest scripts.
- **Indicator naming**: snake_case English aliases (e.g., `gdp_pc_usd`, `enroll_prim_gross`, `ptr_primary`) rather than raw WDI codes — improves downstream readability; mapping preserved in script header comments and in `catalog.yml::variables`.
- **Year buffer**: pulled 1995–2024 (or 2000–2024 for HCI) rather than the brief's 2000–2022 — costs nothing, gives sensitivity headroom. Operational range still locked at 2000–2022 in ADR-0003 (Session 09).
- **HCI excludes HLOS** per plan; HLOS is the headline outcome ingested in Session 04 with its own ADR-0004.
- **R/lib helpers are sourced, not packaged**: project is too small for a real R package; `source("R/lib/...")` at the top of each ingest script is enough.

## Results / findings

- Population: 100% present, 216 countries
- Pupil-teacher ratio (primary): **49% present, 200 countries** — significant downstream constraint
- Education expenditure (% GDP): 58% present, 202 countries
- Primary completion: 56% present, 194 countries

HCI coverage (sparse by design — published in reference years only):
- HCI overall: 585 obs across 169 countries, 2010–2020
- LAYS overall: 585 obs across 169 countries, 2010–2020
- HCI by sex is 12-13% lower coverage than overall
