## Goal

Ingest the **headline outcome variable** — Harmonized Learning Outcomes (HLO) — in two forms: primary (`HD.HCI.HLOS` via WDI API) and principal robustness (Altinok-Angrist-Patrinos 2018, WP 8314). Lock [ADR-0004](../decisions/0004-hlo-measure.md) (Pending → Accepted) with empirical row counts and SSA-coverage gaps recorded. Expand methodology §3.4 to engage the Sandefur (2018) critique with concrete numbers, not a stub.

## What we did

- Located the AAP-2018 dataset via the OWID `owid-datasets` GitHub mirror (raw CSV at a frozen commit). OWID derivation retains a single "Average harmonised learning outcome score" already pooled across subjects (math/reading/science) and levels (primary/secondary) per AAP's method — eliminates the planned subject-collapse step.
- Wrote `R/10_ingest_hlo.R` mirroring the UIS Session-03 pattern: 7 numbered sections (fetch primary, fetch AAP, clean primary, clean AAP, audit + SSA contrast, write interim, two-entry catalog update). Generous `options(timeout=300)` for the WDI API to absorb the occasional >60s response.
- Ran the script end-to-end. Primary: 2277 rows, 207 countries, 2010–2020 (HCI cycles), 74.13% missing within panel. Robustness: 486 rows, 137 countries, 1995–2015 at 5-year intervals (within YEAR_RANGE), 0% missing within its own panel. 5 sub-national rows (BC, England, Scotland, Indiana, Zanzibar) correctly logged to `output/logs/iso3_unresolved_hlo_aap2018.csv` and filtered out.
- Computed SSA-vs-rest-of-world missingness contrast on the full-joined panel: `hlo_score` gap **−3.20 pp** (SSA modestly better); `hlo_aap` gap **+8.75 pp** (SSA worse — empirical face of the Sandefur critique). Persisted to `output/tables/ssa_hlo_missingness.csv` and `output/figures/coverage/ssa_hlo_missingness.{pdf,png}`.
- Locked **ADR-0004 (Pending → Accepted, 2026-05-17)** with "Data observed" subsection (rows / countries / year range / SSA gaps for both measures); updated `docs/decisions/INDEX.md` row.
- Expanded `docs/methodology.md § 3.4` from a 3-line stub to a full block: primary, robustness, Sandefur acknowledged, within-country FE defense ($\alpha_i + \lambda_t$ absorbs cross-country score-comparability noise), SSA coverage caveat with both measures' numbers and the *measurement-availability vs measurement-equating* distinction.
- Bumped data dictionary header timestamp, removed HLO from Pending Sources, inserted two new sections (HLO primary + HLO AAP-2018 robustness).
- Ticked obligations: Data-Integrity "HLO: cite Altinok et al. harmonization methodology and its critics" full tick; Robustness-Spec "HLO measure: WB current vs AAP-2018" partial tick (ingested; sensitivity is Phase 5); SHA-256 row bumped to 6 sources hashed.
- Ticked both lit notes' Read + Notes boxes (`altinok-angrist-patrinos-2018.md`, `sandefur-2018.md`); deferred the Manuscript-engagement box for both until Phase 11 (Quarto draft).

## Decisions made

- **ADR-0004 Accepted** — Option 1 primary (`HD.HCI.HLOS` via WDI) + Option 2 robustness (AAP-2018), Sandefur engaged via within-country FE defense. Now Accepted with empirical "Data observed" block.
- **AAP-2018 sourced via OWID GitHub mirror** — `raw.githubusercontent.com/owid/owid-datasets/.../AAP-2018.csv` provides the harmonized score in a pre-pooled CSV with stable commit-hash pinning. Cleaner than wrangling WP 8314's supplementary files. The pre-pooled score aligns exactly with `HD.HCI.HLOS` semantics. Provenance documented in `data/catalog.yml::hlo_aap2018.notes` and the data dictionary.
- **Two separate catalog entries** (`hlo` primary, `hlo_aap2018` robustness) — distinct access dates, SHAs, and variable slugs render cleanly as two rows in `data/catalog.md` and make downstream merge scripts treat them as independent inputs by slug.
- **Subject-collapse step in plan = no-op** — OWID already pooled subjects/levels. Threshold-share columns (min/intermediate/advanced) dropped — not used in the planned Phase-5 sensitivity (single score is sufficient).
- **5 sub-national rows dropped** (BC, England, Scotland, Indiana, Zanzibar) via the existing `normalize_iso3` → log → `filter(!is.na(iso3))` flow. Not added to the ISO3 override dict — the unresolved-log is the right audit signal for one-off non-country labels.
- **Figure subtitle uses ASCII hyphen** instead of em-dash — sidesteps a locale-encoding warning in `mbcsToSbcs` that surfaced on this run. Cosmetic; no substantive change.

## Results / findings

Two interim parquets:

| Measure | Source | Rows | Countries | Year range | Missing % (own panel) |
|---|---|---|---|---|---|
| `hlo_score` (primary) | WDI `HD.HCI.HLOS` | 2277 | 207 | 2010–2020 | 74.13% |
| `hlo_aap` (robustness) | AAP 2018 WP 8314 (OWID mirror) | 486 | 137 | 1995–2015 | 0.00% |

**Headline SSA-missingness finding** (`output/tables/ssa_hlo_missingness.csv`):

| Indicator | SSA missing % | Non-SSA missing % | Gap |
|---|---|---|---|
| `hlo_score` (HCI HLOS) | 74.40% | 77.60% | **−3.20 pp** |
| `hlo_aap` (AAP-2018)   | 88.02% | 79.23% | **+8.75 pp** |

**Substantive implications:**
- The two measures diverge sharply on SSA representation. The primary HCI measure shows *slightly better* SSA coverage — consistent with post-2017 WB Human Capital Project targeting of low-income measurement gaps.
- The AAP-2018 robustness measure shows the **opposite pattern** (+8.75 pp worse in SSA) — the empirical face of Sandefur (2018)'s pre-2018 SSA-coverage critique: thin SACMEQ/PASEC anchors miss many SSA country-years.
- This is *measurement availability*, distinct from the *measurement equating* version of the Sandefur concern. Both flow into the Discussion §6 limits paragraph on outcome-variable uncertainty.
- The within-country FE defense survives intact: country fixed effects absorb the level-comparability noise Sandefur identifies. Phase 5 will report Model 2 results for both measures; the within-country coefficient must align in sign and approximate magnitude across both for the headline claim to stand.
