## What we tried that didn't work

*Recorded live during this session.*

- **First Bond consistency lm() runs produced "essentially perfect fit" warnings** with all β on log(1+CRS) coefficients = 0.000 and lag_hlo = 1.000. At T = 3-4 cycles, the lagged-DV + country FE + cycle FE + 4-7 controls exhaust degrees of freedom. The Bond bracketing methodology committed to in the plan is NOT informative on this panel — itself a finding. → Reported the degenerate result honestly; the Bond bounds row in the triangulation table shows zeros with high p-values, which IS the empirical reality of the small-T panel.
- **Diff GMM and Sys GMM FULL specs failed to estimate** with matrix singularity errors. With listwise on the full control set the sample collapses to T = 3 × N = 61, below GMM's minimum. → Caught via tryCatch; reported as "failed_to_estimate" in the diagnostics table.
- **First run crashed on `round(ar2_p, 4)` with "non-numeric argument"** because the AR(2) test returned NaN/NULL on small-T GMM runs. → Wrote a `safe_round` helper that handles NA/NaN/NULL gracefully before passing to `round()`. Single fix; clean re-run.
- **Em-dash encoding warnings on figure write** (same gotcha as previous sessions). → Replaced em-dashes with ASCII hyphens in the estimator labels. Plot now renders cleanly.

**Findings:**
1. **Bond bounds degenerate.** Lagged-DV with T=3-4 cycles exhausts degrees of freedom; lag_hlo coefficient ≈ 1.000 absorbs all variance, leaving 0 for ODA. The Bond bracketing methodology committed to in plan.md cannot be applied.
2. **Diff GMM minimal-spec runs cleanly on Hansen** (p=0.498) but β = +0.601 ± 10.6 is uninformatively wide. AR(2) cannot compute (T_eff after differencing = 1).
3. **System GMM minimal-spec produces sign-flipped coefficient** (β = −0.923 ns) — direction opposite to static FE — but **Hansen p = 0.022 rejects instrument validity**. Cannot trust System GMM coefficient over static FE.
4. **Diff/Sys GMM FULL specs fail to estimate** (matrix singularity at T=3 × N=61).
5. **The brief's GMM-as-headline-robustness requirement is not satisfiable on this panel.** Asongu (2019), Yogo (2017) used T ≥ 15-20 annual panels; we have T ≤ 4 HCI cycles. Bond (2002) explicitly warns about this regime.

**The substantive §6 candidate:** the identification limits exposed here are not a methodological weakness but a substantive insight. **Education ODA is measured by donors annually; its outcomes are measured by harmonized testing only at long, irregular intervals.** This treatment-frequency / outcome-frequency mismatch creates exactly the small-T problem that defeats GMM identification. The brief's "measurement architecture" thesis predicts this asymmetry. *World Development* readers may find this story stronger than a single contested GMM coefficient.

**ADR-0010 lock evidence-based:** Path 2 (Option 1 with caveats). Static FE Model 2 (β = +10.95***) remains the headline. Identification defense rests on: two-way FE + cluster SE + Phase-5 Sessions 03/04/05 robustness chain consistency + transparent §3 acknowledgment of GMM limitation.
