## Goal

Phase 4 Session 01: estimate Model 1 — the cross-sectional OLS baseline that establishes the naive between-country association between education ODA and learning outcomes. This β_OLS is the coefficient that Phase 5 Model 2 (within-country FE) will challenge; the β_OLS vs β_FE contrast is the paper's empirical spine.

## What we did

- Wrote `R/50_model1_ols.R` (~200 LOC): six sequential-add specifications × two outcomes (HLO + LAYS) = 12 regressions via `fixest::feols()` with `vcov = "hetero"` (HC-robust SE).
- Computed country-level summary frame `cm` (one row per country, mean across primary window 2010–2020) for all 17 candidate analytical variables.
- Log-transformed skewed regressors: `log1p(crs_disburse_defl_sum)`, `log1p(gcdf_amount_const2021_sum)`, `log(wdi_gdp_pc_usd)`. Other vars (PTR, ed_exp, Gov_effect) used raw.
- Ran six HLO-outcome specs: 1a bivariate → 1f China-robust (full + log GCDF).
- Ran parallel six LAYS-outcome specs (metric translation, not independent robustness).
- Computed VIFs via parallel `lm()` fit per spec (since `car::vif()` doesn't support fixest objects directly); saved to `output/tables/model1_vif.csv`.
- Built modelsummary tables (CSV + manuscript-ready markdown). Wrote directly to file via `output = <path>` (first attempt with `writeLines()` on the modelsummary object failed because the returned object is a knitr_kable, not character).
- Built coefficient forest plot: HLO + LAYS coefficient on log(1+CRS) with 95% CIs across 6 specs, color-coded by outcome.
- Populated `docs/findings.md § 5.1` with the full Model 1 result (coefficient table, full-spec breakdown, VIF readings, substantive read, forward reference to § 5.2 Phase 5).
- Updated `docs/methodology.md § 3.8` Model 1 subsection with the result + pointer.
- Updated `docs/obligations.md`: VIF row `[ ]` → `[~]` (Model 1 VIFs computed; Model 2 VIFs Phase-5).

## Decisions made

- **`fixest::feols` with `vcov = "hetero"`** for HC-robust SE (one observation per country reduces cluster-robust to HC robust). Equivalent to `sandwich::vcovHC(., type = "HC1")` by fixest convention.
- **Six sequential-add specs** (bivariate → +log GDP/cap → +PTR → +ed exp [brief spec] → +Gov effect [full] → +log GCDF [China-robust]). Pattern matches standard panel-paper presentation.
- **LAYS as outcome is a parallel column-set, not separate robustness.** LAYS = EYS × HLO/625 (WB methodology) is a deterministic transform of HLO; the LAYS-outcome regressions translate results into GEEAP/Angrist-comparable years-of-learning units but provide no independent evidence. Documented in the table caption.
- **VIF computed on parallel `lm()`** (fixest doesn't integrate with `car::vif()`). Max VIF in full spec = 5.24 on log(GDP/cap); below the 10 threshold and milder than Session 12's r=0.79 might have predicted.
- **Coefficient plot shows ODA coefficient only** (not all coefficients in all specs — would be unreadable). Focus on the headline ODA β across the spec progression.

## Results / findings

**Headline Model 1 result on log(1 + CRS_disburse_defl_sum):**

| Spec | β | SE | p | N | R² |
|---|---|---|---|---|---|
| 1a — bivariate | **−11.537*** | 2.715 | <0.001 | 133 | 0.154 |
| 1b — + log(GDP/cap) | −1.204 | 2.280 | 0.598 | 133 | 0.397 |
| 1c — + PTR | −1.141 | 2.439 | 0.640 | 125 | 0.396 |
| 1d — + ed exp (brief spec) | −1.787 | 2.595 | 0.493 | 120 | 0.402 |
| 1e — + Gov effect (full) | **−1.361** | 2.477 | 0.584 | 120 | 0.444 |
| 1f — + log(GCDF) | −1.150 | 2.413 | 0.633 | 120 | 0.445 |

**The cross-sectional ODA-learning association is large, negative, and significant — and entirely absorbed by income + governance controls.** Bivariate β = −11.5 drops to −1.4 (ns) when log(GDP/cap), PTR, ed exp %, and WGI governance enter. This is selection: countries that receive more education aid are poorer + worse-governed, and those structural factors drive HLO outcomes.

**Other full-spec (1e) coefficients:**
- Govt effectiveness (WGI): **+24.51*** (p<0.01)** — the dominant cross-sectional correlate
- log(GDP per capita): +9.30 (ns; was +26.25*** in 1b before WGI entered)
- PTR primary: −0.54 (ns; expected sign)
- Ed exp % GDP: −1.02 (ns; surprising negative — compositional %-GDP effect)
- log(GCDF) Chinese aid: −0.31 (ns) — Chinese aid coefficient is also null cross-sectionally

**VIF diagnostic (full spec):** log(GDP/cap) = 5.24; Gov effectiveness = 2.95; PTR = 2.64; log_CRS = 1.60; ed_exp = 1.13. Only log(GDP/cap) marginally above the standard threshold of 5 (and well below 10). The Session-12 prediction of severe multicollinearity from the bivariate r=0.79 was milder in the multivariate setting because PTR + ed exp partially absorb the governance-income shared variance.

**LAYS-outcome variant (same 6 specs):** ODA coefficient on LAYS in full spec = −0.018 (ns). Metric translation of HLO results into years-of-learning units for GEEAP / Angrist 2024 comparability. Not independent evidence.

**The Model 1 → Model 2 contrast is the paper's empirical spine.** Phase 5 Model 2 will run the within-country FE specification on the same regressors; the β_FE vs β_OLS contrast is the headline result.
