## Decisions made

- **Lock ADR-0009 with Option 1 (PCA-collapsed PC1) as primary.** Single GE (Option 2) and all-six (Option 3) reported as parallel robustness. Option 4 (per-source reconstruction) formally deferred — not needed.
- **Overrode the ADR's stated working preference (Option 3 primary with Option 1 as robustness)** — the ADR explicitly deferred until "VIF is observed"; Session-05 observation is now in hand. Max VIF on demeaned spec B = 4.71 (within ≤5 viability threshold) confirms Option 3 is feasible, but Option 1 is the more substantive Langbein-Knack engagement.
- **Overrode the Session-05 plan's pre-grid default (Option 2 single GE primary)** — plan's parsimony argument was superseded by Session-05 empirical evidence: PC1 captures 76.4% of WGI variance, β_ODA = 11.1 at p = 0.048 (only spec crossing conventional 0.05 threshold), all-positive loadings make PC1 interpretable as "overall governance quality."
- Both overrides documented explicitly in the ADR's "Override note" section to preserve the reasoning trail.

## What we tried that didn't work

- **PC1 sign-flip logic preserved but not triggered.** Script includes the conventional flip (if `wgi_ge_est` loading on PC1 < 0, flip sign and scores) — but on this sample `prcomp` returned GE loading positive on first call, so no flip was needed. The logic stays in the script for reproducibility across panels where the sign could come out the other way.
- **Considered keeping Option 2 (single GE) as primary** with PC1 as robustness — the plan's pre-grid default. Rejected after seeing the empirical evidence: PC1 directly engages Langbein-Knack quantitatively (the lit note pre-commits us to PCA or per-source reconstruction; PC1 is operational without additional ingest), and is the strongest empirical spec. The parsimony argument for single-GE is reportable but secondary to the L-K engagement requirement.
- **Plot has font-encoding warnings** for em-dash (—) and β characters in the default PDF font (`mbcsToSbcs` conversion failures). Cosmetic only — the data renders fine; em-dashes get substituted as dots and β as Greek beta would render in a font with greek glyphs. Not fixing this session; future plot regen should use ASCII labels or change the PDF device font. Documented as a future polish item, not a blocker.

**Lock criterion verification:**
- Max VIF on spec B (demeaned): 4.71 — within ≤5 viability ✓
- β_ODA stability across A/B/C: shifts 0.43 SD / 0.60 SD (both within ±1 SD criterion) ✓
- Spec A vs D: β shifts 0.12 SD — WGI is doing minimal direct work on β_ODA in single-GE form, but broader WGI captures more confounding variance

**Descriptive evidence (Langbein-Knack engagement):**
- PC1 variance share: **76.4%** (PC2: 10.9%; PC3: 6.5%) — within L-K predicted 60-80% range; quantitative confirmation of "essentially one factor" claim
- PC1 loadings: all positive in 0.35-0.45 band; RL=0.45, CC=0.44, GE=0.43, RQ=0.41, PV=0.37, VA=0.36
- Per-dimension WGI coefficients in spec B: all 6 are ns at p<0.10 with mixed signs (VA=−26.2, PV=+2.3, GE=+9.9, RQ=+44.9, RL=−9.4, CC=+32.7) — direct empirical L-K (collinearity prevents individual identification despite joint significance)

**Convergent evidence across three Phase-5 robustness sessions:**
1. Session-03 16-cell treatment-encoding grid: all 16 HLO β ≥ 0; lock at β=8.17, p=0.10 on the strictest spec
2. Session-04 China-aid robustness: β stays 8.17 → 8.06 when GCDF added; OECD-only is non-DAC-blind-spot robust
3. Session-05 WGI operationalization: PC1 → β=11.1 at p=0.048; ODA positive within-country effect crosses conventional significance on the L-K-engaging spec

The pre-Phase-5 "ODA does not predict learning" framing is now unambiguously outdated across three independent strands. §6 framing reframe is author's call (paths a/b/c per findings.md §5.2.1).
