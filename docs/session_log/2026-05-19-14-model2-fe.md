## Goal

Phase 5 Session 01: estimate Model 2 — the within-country fixed-effects panel. The β_OLS (Model 1 = −1.36 ns) vs β_FE (Model 2 = ?) contrast is the manuscript's central empirical claim. All four required diagnostics (Hausman, Wooldridge, Breusch-Pagan, VIF) run on the full spec. Populate `findings.md § 5.2` with the headline.

## What we did

- Wrote `R/51_model2_fe.R` (~330 LOC): 7 sequential-add FE specs × 2 outcomes (HLO + LAYS) = 14 regressions via `fixest::feols(. | iso3 + year, vcov = ~iso3)` (country-clustered SE).
- Implemented COVID-days NA→0 recode for pre-2020 years (UNESCO COVID source covers 2020-2022 only; recode treats pre-pandemic years as 0 closure exposure rather than "missing"). This is a substantive modeling choice extending the production panel's NA→0 convention from aid flows to COVID exposure. Documented in script header + findings.md.
- Ran 4 diagnostics via plm + lmtest + car parallel fits:
  - Hausman: FAILED (Swamy-Arora RE needs > 3 time periods; HCI cycles provide only 4 effective points per country). Defers to Phase 5 Session 05.
  - Wooldridge AR(1): F = 0.252, p = 0.62 (no serial autocorrelation — HCI cycle spacing of 7+ years makes AR(1) non-binding)
  - Breusch-Pagan: χ² = 137, p = 0.0045 (heteroskedasticity present — country-clustered SE warranted, applied)
  - VIF on within-demeaned regressors: max = 1.64 (well below the 10 threshold; within-FE absorbs the cross-sectional governance × income multicollinearity)
- Built Model 1 vs Model 2 contrast table (`output/tables/model1_vs_model2_contrast.{csv,md}`) and 2-panel coefficient plot showing the sign flip + magnitude amplification visually.
- Populated `findings.md § 5.2` fully (replacing the stub); documented the three interpretive paths held open until Phase-5 robustness chain completes.
- Updated `methodology.md § 3.8` Model 2 subsection with headline numbers + diagnostic summary; timestamp bumped.
- Updated `obligations.md`: ticked 5 of 6 Model-2 diagnostic obligations (Wooldridge, BP, VIF, Year FE, cluster SE = full ticks; Hausman = partial-tick deferred to Session 05).

## What we tried that didn't work

*Recorded live during this session — high confidence.*

- **`filter(complete.cases(.))` failed in dplyr.** The `.` placeholder doesn't refer to the data frame inside filter; you can use it in pipe transforms but not as an argument to complete.cases. → Replaced with `as.data.frame() |> na.omit()`. Same effect; works correctly.
- **modelsummary's `gof_map` choked on tribble rows with NULL `fmt` values.** I had tried to add "FE: iso3" and "FE: year" rows with `fmt = NULL` to display FE indicators, but the underlying parsing expects every row to have a numeric fmt. → Stripped the FE rows from gof_map (they're shown in the modelsummary default output anyway when fixest objects pass through). The N/R²/Adj R² rows now render cleanly.
- **Hausman RE estimation crashed** with the error "model not estimable: 6 coefficient(s) (incl. intercept) to be estimated but only 3 time(s) in data for the between model necessary for Swamy-Arora random-effect model estimation." → Caught via tryCatch; documented in diagnostics table as deferred; the FE specification is theoretically justified per Mundlak regardless.

## Results / findings

**Headline contrast** (`output/tables/model1_vs_model2_contrast.md`):

| Model | N | β on log(1+CRS) | SE | p |
|---|---|---|---|---|
| **Model 1 OLS, full spec (1e)** | 120 | **−1.36** | 2.48 | 0.584 |
| **Model 2 FE, full spec (2e)** | 143 | **+10.95** | 3.60 | **0.003** |
| Model 2 FE +conf+COVID (2g) | 143 | +10.83 | 4.03 | 0.009 |

**Sign flips. Magnitude is ~8× larger when within-country FE applied. p < 0.01.**

**Model 2 spec progression** (`output/tables/model2_fe_baseline.md`):

| Spec | N | β | SE | p |
|---|---|---|---|---|
| 2a — bivariate | 441 | 2.09 | 2.21 | 0.346 |
| 2b — + log(GDP/cap) | 437 | 2.20 | 2.39 | 0.358 |
| 2c — + PTR primary | 184 | **13.33** | 5.59 | 0.018 |
| 2d — + ed exp (brief spec) | 143 | **13.77** | 4.95 | 0.007 |
| 2e — + Gov effectiveness (full) | 143 | **10.95** | 3.60 | 0.003 |
| 2f — + log(1+GCDF) | 143 | 11.04 | 3.69 | 0.004 |
| 2g — + conflict + COVID | 143 | 10.83 | 4.03 | 0.009 |

PTR primary sharpens the result dramatically (2c jumps from +2.1 ns to +13.3*). Subsequent controls leave the headline coefficient in the +10 to +14 range — robustness across the controlled spec progression is encouraging.

**Diagnostics** (full spec 2e; `output/tables/model2_fe_diagnostics.csv`):
- Hausman: failed (small-T limitation; FE justified per Mundlak)
- Wooldridge AR(1): F = 0.252, p = 0.62 (no AR(1))
- Breusch-Pagan: χ² = 137, p = 0.0045 (heteroskedasticity; cluster-robust SE applied)
- VIF max on demeaned regressors: 1.64 (well below 10; within-FE absorbs cross-sectional collinearity)

**Substantive read:** a country moving from $10M to $100M average annual education disbursement (a log change of ~2.3) would experience a within-country HLO gain of ~25 points — roughly half a within-universe SD. Meaningful magnitude, not a statistical curiosity.

**The brief's falsification standard is satisfied at static FE.** Brief: *"if the within-country coefficient on ODA is positive, significant, and meaningful in magnitude, the thesis fails."* The Phase-5 robustness chain (System GMM, lag structure, China-aid, WGI operationalization across Sessions 02-05) will determine whether this is genuine falsification, fragile to thin data, or heterogeneous by subgroup. Three interpretive paths held open in findings.md § 5.2.
