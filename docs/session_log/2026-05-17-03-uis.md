## Goal

Ingest UNESCO UIS (private expenditure + out-of-school rates), and characterize the SSA missingness pattern that feeds [ADR-0006](../decisions/0006-uis-missingness-strategy.md). Scope deliberately minimal: only what WDI doesn't already cover.

## What we did

- Probed UIS bulk URLs — canonical `uis.unesco.org/sites/...` returned fake 200s (landing page). Scraped `https://databrowser.uis.unesco.org/resources/bulk` via `rvest` to find real download links: `https://download.uis.unesco.org/bdds/202602/SDG.zip` (34 MB) and `OPRI.zip`.
- Downloaded SDG.zip (sha256 `8f68d5d01e2f…`); unzipped to find SDG_DATA_NATIONAL.csv (75 MB, 1.46M rows, long format) + SDG_LABEL.csv (code → label map).
- **Ground-truthed pinned indicator codes against actual UIS labels.** Three substitutions required:
  - `XGDP.FSHH.FFNTP` → `XGDP.FSHH.FFNTR` (only "Initial" variant available in current UIS release)
  - `XGDP.FSGOV.FFNTP` → `XGDP.FSGOV` (UIS simple total — cleanest WDI cross-check)
  - `ROFST.<lvl>` → `ROFST.<lvl>.CP` (UIS uses `.CP` for "cumulative percentage")
  - All substitutions documented in script header, catalog `notes`, and data dictionary.
- Wrote `R/10_ingest_uis.R`: read SDG_DATA_NATIONAL.csv with on-the-fly indicator filter (avoids loading all 1.46M rows), pivot wide on indicator, normalize ISO3, write `data/interim/uis.parquet`.
- Ran `ssa_missingness_pattern()` with SSA universe derived from `countrycode::codelist` (48 SSA ISO3 codes). Output: `output/tables/ssa_uis_missingness.csv` + `output/figures/coverage/ssa_uis_missingness.{pdf,png}`.
- Updated documentation layer per the strengthened CLAUDE.md protocol.

## Results / findings

UIS ingest: **7059 rows, 220 countries, years 1970–2025, 9 columns** (iso3, year + 7 indicators).

**Headline SSA missingness finding** (`output/tables/ssa_uis_missingness.csv`):

| Indicator | SSA miss % | Non-SSA miss % | Gap |
|---|---|---|---|
| Private expenditure as % GDP | **91.8%** | 80.3% | +11.6 pp |
| Gov expenditure as % GDP (UIS) | 29.5% | 26.1% | +3.4 pp |
| OOS primary, both sexes | 32.3% | 33.9% | **−1.6 pp** |
| OOS primary, female | 38.7% | 51.5% | **−12.8 pp** |
| OOS primary, male | 38.7% | 51.5% | **−12.8 pp** |
| OOS lower secondary | 62.2% | 51.3% | +10.9 pp |
| OOS upper secondary | 65.0% | 51.7% | +13.3 pp |

**Substantive implications:**
- Private expenditure is **effectively unusable** for SSA-inclusive primary specifications (>90% missing). Strong working preference: primary spec uses WDI controls only; UIS-augmented spec as robustness only.
- Primary OOS rates show SSA *better* than non-SSA — counterintuitive but real, likely reflects UN universal-primary-monitoring priority during the MDG era. Worth noting in §4.1 descriptives (the brief's "enrollment vs learning divergence" framing).
- Lower / upper secondary OOS missingness is consistently worse in SSA — secondary monitoring is weaker than primary across the board.
